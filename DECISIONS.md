# Инженерные решения

- CSV выбран потому, что тестовое разрешает самостоятельно собрать тестовые данные и не требует интеграции с маркетплейсом.
- Прототип запускается локально и использует стандартную библиотеку Python.
- AI-разметка вынесена в отдельную функцию; ответ проверяется по допустимым темам и тональности.
- По умолчанию отправки в Telegram нет: это предотвращает случайные сообщения при тестировании.
- Эвристический режим используется только как smoke test без API, а не как замена LLM.
- Для проверки качества предусмотрен шаблон ручной разметки; перед сдачей нужно заполнить его на 10–15 примерах и указать фактические результаты.
- Важный известный пробел для production: надо добавить надёжную дедупликацию по marketplace review ID, ретраи, структурированные логи и тесты на внешние API.
